# DiaTweaks for Windows

Make more room for the web, give Dia your own colors, and jump to a page with **Alt + Space**.

[**Download for Windows 11 x64**](https://github.com/Advay-01/windows-dia/releases/download/windows-preview-v0.1.0/DiaTweaks-Windows-x64.zip) · [Release notes](https://github.com/Advay-01/windows-dia/releases/tag/windows-preview-v0.1.0) · [macOS project](https://github.com/JaceThings/DiaTweaks)

## Get started

1. Install [Dia](https://www.diabrowser.com) on Windows 11 x64.
2. Extract the whole ZIP into a folder and double-click `DiaTweaks.exe`.
3. In Dia, open **Settings → Patches**. It’s right below **Advanced**.

DiaTweaks stays in the Windows notification area and remembers your switches. You can turn all patches off or quit from its tray menu. If you're upgrading from an older build, fully quit Dia and DiaTweaks before replacing the extracted files.

## Three places to start

| Feature | Where to find it | What you can do |
| --- | --- | --- |
| **Patches** | **Settings → Patches** | Extend pages edge to edge, square the corners next to the sidebar, hide the toolbar with optional hover reveal, or hide the sidebar and Chat buttons. [Watch the Patches demo](https://github.com/Advay-01/windows-dia/releases/download/windows-preview-v0.1.0/demo-patches.mp4). |
| **Themes** | Right-click an empty area of the sidebar → **Themes** | Drag color points to style the sidebar and frame. Double-click a point for RGB or hex entry, then adjust opacity and grain. The selected tab lets the theme show through. [Watch the Themes demo](https://github.com/Advay-01/windows-dia/releases/download/windows-preview-v0.1.0/demo-themes.mp4). |
| **Quick search** | **Alt + Space** | Open a URL, search the web, or jump to a matching recent Dia tab or Top Site. The acrylic panel starts with just the search field. It shows results as you type. |

If **Alt + Space** is already in use, try **Ctrl + Alt + Space**. Use the arrow keys to pick a result, **Enter** to open it, and **Esc** to close the panel. Top Sites use Dia’s local browsing history.

## Preview status

I tested this on Windows 11 x64 with Dia **1.4.0.424**. The sidebar layout got the most live testing. Caption colors are experimental, and the Chats and Recent Tabs switches still need Windows support. The recordings show the controls during development.
